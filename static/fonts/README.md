# Vendored theme title fonts

These fonts are bundled with Orange so all theme branding works completely offline.

- Arcade: Permanent Marker — Google Fonts `apache/permanentmarker` — Apache-2.0
- Cyber: Jersey 25 — Google Fonts `ofl/jersey25` — SIL OFL 1.1
- Princess: Sacramento — Google Fonts `ofl/sacramento` — SIL OFL 1.1
- Adventure: Fraunces — Google Fonts `ofl/fraunces` — SIL OFL 1.1
- Midnight: Faculty Glyphic — Google Fonts `ofl/facultyglyphic` — SIL OFL 1.1

The checked-in WOFF2 files are locally served by Orange. No Google Fonts/CDN request is made at runtime.
Original license texts are in `licenses/`.
