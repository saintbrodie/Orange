# Documentation screenshots

`tools.webp`, `preflight.webp`, and `curated-library.webp` were refreshed for
Orange v1.1 on 2026-11-13, at a 1600-pixel browser width.

These captures use demonstration configuration on the current UI rather than
publishing deployment settings. The Tool Editor shows the optional first-frame
workflow setup. Preflight demonstrates duplicate VAE filenames and the backend
binding selector; it is an example diagnostic, not a report about the reader's
backend. The library capture shows all seven packs and the filter tags.

The other screenshots illustrate the existing generator, setup, personalization,
settings, and analytics surfaces. Screenshots are encoded as WebP for the README.
